# PETA FITUR & ARSITEKTUR LIVERA APP

Dokumen ini menyajikan inventarisasi lengkap, analisis mendalam, alur kerja teknis, serta status verifikasi implementasi dari seluruh modul dan fitur pada proyek **LIVERA** (`livera_app`).

---

## 1. Arsitektur & Topologi Sistem

Aplikasi LIVERA adalah aplikasi multi-platform (Android, iOS, Web, Windows, macOS, Linux) berbasis **Flutter 3.x / Dart 3.x** yang dirancang sebagai antarmuka pintar untuk memantau dan mengendalikan bioreaktor mikroalga (*Chlorella vulgaris*).

### Komponen Sistem:
1. **Frontend Client (Flutter App)**:
   - State Management: `Provider` (`UserProvider`, `ThemeProvider`).
   - Persistent Storage: `shared_preferences` (menyimpan `jwt_token`, `saved_serial`, `is_premium`, dll.).
   - Multi-Bahasa: `easy_localization` (Bahasa Indonesia & English US).
   - Local Notifications: `flutter_local_notifications` (peringatan darurat gas CO2 berlebih, pH kritis, dan kegagalan lampu).
   - Dokumen & Cetak: `pdf`, `printing`, `screenshot` (ekspor laporan analitis).
2. **Backend Server (REST API)**:
   - Base URL: `https://livera.mataramteachingfactory.store/api`
   - Framework: Golang Gin Engine dengan database relasional PostgreSQL.
3. **Cloud Realtime Database (Firebase)**:
   - Endpoint: `https://livera-6a8d7-default-rtdb.asia-southeast1.firebasedatabase.app`
   - Digunakan untuk otentikasi alternatif, sinkronisasi realtime node `/devices`, dan FlutterFire.
4. **Hardware Simulator / IoT Firmware (ESP32)**:
   - Firmware: C++ Arduino (`lib/livera_hardware/main.ino`) disimulasikan menggunakan Wokwi (`wokwi.toml`, `diagram.json`).
   - Sensor: MQ-135 (Gas CO2/VOC/Amonia), DS18B20/Potentiometer (Suhu), LDR (Cahaya), pH Sensor, O2 Sensor.
   - Aktuator: Fan/Blower PWM (aerasi), LED Grow Lights, LCD I2C 16x2.
   - Protokol IoT: Blynk Cloud IoT Platform.
